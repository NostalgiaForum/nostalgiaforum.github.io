KillBearBoys3 is a SQLite3 logger. Originally created by ljyloo, the 3rd version was never finished. Here you can find updated KBB3 which fixes a lot of bugs and makes it usable on server.

Features
  • Touch action logging(only chest and furnace)
  • Fixed some SQLite3 problems
  • Logger works on Europe/Kiev timezone.
  • Removed useless commands and features
  • NostalgiaCore 1.1.0 support
  • PHP8 support
Changelog
  • beta7
    • /co can be used by multiple players at once
  • beta7.1
    • Day of week will now show.
    • Date Format is nowDD/MM/YYYY
  • beta8
    • Added rollback
Commands
  • /co - Enable log viewing mode.
  • /rb <player> <time>|all - Rollback all <player> actions or actions after <current_time> - <time>
    • Time Format example: 1w2d3h4m5s - 1 week 2 days 3 hours 4 minutes 5 seconds
      • w/week/weeks - weeks, 604800 seconds
      • d/day/days - days, 86400 seconds
      • h/hours/hour - hours, 3600 seconds
      • m/min/mins/minutes/minute - minutes, 60 seconds
      • s/sec/secs/seconds/second - seconds, 1 second
  • /unrb - Cancel all rollbacked actions in the area
  • /rbpos1 - Set position 1 of the rollback area
  • /rbpos2 - Set position 2 of the rollback area
  • /rbwand - Enable/Disable Rollback selection by wand item
Config
  • wand-itemid - Wand Item ID(Default: 292(Iron Hoe))
Note on PHP5 support
  • The plugin should work fine with PHP8 and PHP5, but PHP5 version is not tested very much. If you have any issues with PHP5, let me know either in discord(.GameHerobrine2 sp00nd bad admin#5208 or GameHerobrine#3030), or here
