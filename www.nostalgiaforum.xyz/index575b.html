Как легко и быстро нарисовать gui_blocks.png

Вы сделали/портировали текстур-пак, а нарисовать gui_blocks очень трудно? Сейчас вы узнаете как можно нарисовать его за минуту. Что нам понадобиться: - Компьютер/ноутбук; - Minecraft 1.4.7/1.4.6; - Gimp, Photoshop или paint.net (не используйте обычный paint!); - Ваш terrain.png и gui_blocks.png. Приступим. 1. Установите ваш terrain.png в MC1.4.7, сделать это двумя способами: кинуть в minecraft.jar, или установить как текстур-пак. 2. Зайдите в MC, установите в настройках gui до больших размеров, разверните игру на весь экран. 3. Откройте любой мир в креативе. 4. Расположите в большом сундуке и инвентаре блоки так, как они лежат в gui_blocks. 5. Сделайте скриншот. 6. Откройте скриншот и gui_blocks в графическом редакторе, переместите блоки со скриншота в gui_blocks. Поздравляю! Вы сделали свой gui_blocks! Пост взят с 4PDA, https://4pda.to/forum/index.php?showtopic=260256&view=findpost&p=23353449 English version: https://www.minecraftforum.net/forums/minecraft-pocket-edition/mcpe-texture-packs/1972753-gui_blocks-png-step-by-step-tutorial

Режимы прорисовки в Minecraft Pocket Edition

Режимов прорисовки всего 9 - от 0 до 8, остальные почти одинаковы - ничего не видно (даже блок в руке отображается криво, либо не отображается), фон либо синий, либо черный (вожможно - белый). Дальность прорисовки -1: Как и где менять? В файле options.txt, который находится по пути: /sdcard/games/com.mojang/minecraftpe/options.txt меняете gfx_renderdistance:n, где n - число. Нормальные режимы (3 - 0): Прорисовка 3. Этот режим используется в игре при минимальной прорисовке. Прорисовка 2. Этот режим используется в игре при максимальной прорисовке. Прорисовка 1. Не используется в игре. На слабых устройствах может начаться подтормаживание и пропадание текстур. Прорисовка 0. Не используется в игре. Туман очень далеко (видно всю карту). На слабых устройствах может начаться подтормаживание и пропадание текстур. Режимы с очень маленькой прорисовкой (4 - 8): Прорисовка 4. Видно лишь 1 чанк (16х16 блоков), и то - неполностью. Фон белый, чего нет в других режимах. Тумана нет. Прорисовка 5. Видно примерно половину чанка. Туман есть. Прорисовка 6. Видно четверть чанка. Прорисовка 7. Видно 1/8 чанка. Прорисовка 8. Видно лишь предмет в руке. Материал был взят с 4PDA, https://4pda.to/forum/index.php?showtopic=260256&view=findpost&p=23296281

Adding servers on older versions

In this tutorial, I will tell you how to add servers on versions below 0.7.6. As you know, in these versions, there is no direct addition within the game itself. But first, let's start with versions above 0.7 Launch the game Click on the "Play" button on the main page. Click on the "Edit" button, then "External". In the "Server Name" field, enter the server's name. It can be anything and will be displayed in the server list. Enter the IP address/domain of the server in the "Address" field. Enter the port in the "Port" field. If the server's port is 19132, you can leave it unchanged. After filling in all the fields, click the "Add server" button. Now let's learn how to add servers on versions below 0.7.6 This method works for versions: 0.8.1, 0.7.6, 0.6.1, 0.5.0, 0.4.0, 0.3.3, 0.2.2, 0.1.3, 0.1.1 Download the program PyDroid 3 (> Click <) Upload the required file (> Click <) Open the downloaded PyDroid. Click on the folder icon in the top right corner, then click "Open". Find and open the downloaded file (proxy.py). Find the 76th line, and replace 'myserver.ddns.net' with the IP/domain of the server you want to connect to. If you want to change the standard port (19132), find the line 10, and change 19132 to your port. Click on the start button at the bottom right corner. Click on the space icon next to the TAB button in the upper right corner. Open Minecraft, and the server should appear in the server list. If you do not understand something, you can watch this video: Thanks to @ArkQuark for this tutorial.
