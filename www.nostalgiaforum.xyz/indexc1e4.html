In this tutorial, I will tell you how to add servers on versions below 0.7.6. As you know, in these versions, there is no direct addition within the game itself.​


But first, let's start with versions above 0.7
  1. Launch the game
  2. Click on the "Play" button on the main page.
  3. Click on the "Edit" button, then "External".
  4. In the "Server Name" field, enter the server's name. It can be anything and will be displayed in the server list.
  5. Enter the IP address/domain of the server in the "Address" field.
  6. Enter the port in the "Port" field. If the server's port is 19132, you can leave it unchanged.
  7. After filling in all the fields, click the "Add server" button.
Now let's learn how to add servers on versions below 0.7.6
This method works for versions: 0.8.1, 0.7.6, 0.6.1, 0.5.0, 0.4.0, 0.3.3, 0.2.2, 0.1.3, 0.1.1
  1. Download the program PyDroid 3 (> Click <)
  2. Upload the required file (> Click <)
  3. Open the downloaded PyDroid.
  4. Click on the folder icon in the top right corner, then click "Open".
  5. Find and open the downloaded file (proxy.py).
  6. Find the 76th line, and replace 'myserver.ddns.net' with the IP/domain of the server you want to connect to.
  7. If you want to change the standard port (19132), find the line 10, and change 19132 to your port.
  8. Click on the start button at the bottom right corner.
  9. Click on the space icon next to the TAB button in the upper right corner.
  10. Open Minecraft, and the server should appear in the server list.
